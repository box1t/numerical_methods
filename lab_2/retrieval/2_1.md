
# Решение нелинейных уравнений

- функция - эквивалентный вид уравнения. абсциссы точек пересечения построенных графиков.

- отделение
- уточнение выделенного корня с заданной точностью


## Теорема [2]

- Непрерывная строго монотонная f(x) имеет единственный нуль на отрезке, когда на его концах значения разных знаков.
- Достаточный признак монотонности f(x) на [a,b] - сохранение знака производной функции.


## Метод Ньютона
- итерационный процесс, формула
- проверка: произведение функции на её производную больше нуля в точке начального приближения (которое указал пользователь из выбранного отрезка)
- Условие окончаний итераций: модуль разности последующего приближения минус текущего приближения меньше эпсилон.
Тогда неподвижная точка стремится к последующему приближению.

## Метод простых итераций
- решение через последовательность эквивалентных уравнений (x = fi(x))
